ABOUT THE LIVE VIDEO BACKGROUND
--------------------------------
Your brief specifies a full-screen video background from a file called
"1000205679.mp4" — that video was not included in your upload, so it
isn't in this package.

The site is already wired for it:
1. Add your video file to the assets folder and name it exactly:
   assets/live-wallpaper.mp4
2. Reload the page — it will autoplay, loop, and stay behind all content.

Until that file is added, the site automatically shows an elegant
animated dark/gold gradient in its place, so the page never looks broken.
